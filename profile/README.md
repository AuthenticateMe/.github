## 👋 Welcome

Hi! You've found the GitHub home of **AuthenticateMe** — the team building security tools that make Discord a safer place for everyone. Our flagship product is the AuthenticateMe verification app: a fast, modern, OAuth-based verification system that stops bots, alts, and bad actors *before* they ever set foot inside a community.

We're a small, focused team that believes **base protection shouldn't cost money**. Every essential security feature in our app is free; Premium only exists to cover features with a direct cost to operate.

## 🛡️ What we build

- **AuthenticateMe Verification** — One-click, OAuth-based Discord verification with deep threat detection (VPN, alt-account, disposable email, anti-detect browser, fingerprinting, and more)
- **AuthenticateMe Dashboard** — Web-based configuration UI used by tens of thousands of server owners
- **Internal infrastructure** — High-availability sharded clusters, threat-intelligence pipelines, and the APIs that keep all of the above running 24/7

## 🚀 Want to use AuthenticateMe?

You don't need to clone anything. AuthenticateMe runs as a fully managed service.

1. **[Add the app to your server](https://discord.com/oauth2/authorize?client_id=1011135011413577768)**
2. **Configure** — use `/setup` in Discord, or the [web dashboard](https://dashboard.authenticateme.xyz/)
3. **Done** — your community is now protected

Want to go further? Check out [Premium](https://authenticateme.xyz/premium) for advanced threat detection.
